== 前置条件

=== Docker

运行 Milvus 向量数据库：
[source,console]
----
docker compose up -d
----

=== Ollama

安装并运行 link:https://ollama.com/[Ollama]，下载所需模型：
[source,console]
----
ollama pull qwen2.5:0.5b
ollama pull bge-m3:latest
----

=== 硅基流动 API Key（可选，用于 Rerank）

从 link:https://cloud.siliconflow.cn/[硅基流动控制台] 获取 API Key。

== 配置

=== 环境变量

[source,console]
----
# Rerank 功能 (可选)
export SILICONFLOW_KEY=<你的硅基流动API Key>

# Redis Cloud (可选，用于 BM25 索引持久化)
export REDIS_HOST=<Redis 云服务地址>
export REDIS_PORT=6379
export REDIS_PASSWORD=<Redis 密码>
----

=== 应用配置 (application.properties)

[source,properties]
----
# --- 模型提供者配置 ---
# 可选值: ollama, openai
# 默认使用 ollama
chat.provider=openai

# --- Ollama 配置 (当 chat.provider=ollama 时生效) ---
spring.ai.ollama.base-url=http://127.0.0.1:11434
# Embedding 模型
spring.ai.ollama.embedding.options.model=bge-m3:latest
# Chat 模型
spring.ai.ollama.chat.options.model=qwen2.5:0.5b

# --- OpenAI 配置 (当 chat.provider=openai 时生效) ---
# 推荐使用环境变量 SILICONFLOW_KEY 设置 API Key
spring.ai.openai.api-key=${SILICONFLOW_KEY:}
spring.ai.openai.base-url=https://api.siliconflow.cn
spring.ai.openai.chat.model=Qwen/Qwen3-8B

# --- Milvus 向量库配置 ---
spring.ai.vectorstore.milvus.client.host=10.1.1.234
spring.ai.vectorstore.milvus.client.port=19530
spring.ai.vectorstore.milvus.collection-name=paper_collection_vpdf

# --- RAG 检索配置 ---
# 初筛召回数量
topk=10
# Rerank 精排开关
rerank.enabled=true
rerank.model=BAAI/bge-reranker-v2-m3
rerank.topN=5

# --- 文档处理与切块配置 ---
# 切块算法: markdown (默认, 基于语义) 或 token (基于长度)
chunking.algorithm=markdown

# Markdown 切块参数
chunking.markdown.chunkTokenNum=4096
# 语义分割符
chunking.markdown.delimiter=\n!?;。；！？
# 表格单独切块
chunking.markdown.separateTables=true

# --- DeepSeek-OCR 配置 ---
# 启用 DeepSeek OCR 处理 PDF
deepseek-ocr.enabled=true
deepseek-ocr.model=deepseek-ai/DeepSeek-OCR

# --- 混合检索配置 (Lucene BM25 + Milvus Vector) ---
# 开启后使用 BM25 关键词检索 + 向量语义检索，RRF 融合结果
hybrid.search.enabled=true
hybrid.search.rrf.k=60
hybrid.search.dense.weight=0.7
hybrid.search.sparse.weight=0.3

# --- Redis 持久化 (可选，用于 BM25 索引持久化) ---
spring.data.redis.host=${REDIS_HOST:localhost}
spring.data.redis.port=${REDIS_PORT:6379}
spring.data.redis.password=${REDIS_PASSWORD:}
----

== RAG 工作流程

[source]
----
1. 用户提问
      │
2. 混合召回 (hybrid.search.enabled=true 时)
   ├── BM25 关键词检索 (Lucene 内存索引)
   └── 向量语义检索 (Milvus TopK)
      │
3. RRF 结果融合
      │
4. Rerank 精排 (SiliconFlow TopN=5) [可选]
      │
5. 构建 Prompt + 上下文文档
      │
6. LLM 生成回答 (Ollama/OpenAI)
      │
7. 返回结果
----
