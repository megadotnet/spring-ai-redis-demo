== Pre-requisites

=== Docker

This demo requires Docker to build and run the application.

=== OpenAI

Obtain your OpenAI `endpoint` (e.g. `https://api.siliconflow.cn`) and `api-key` from the  OpenAI Service section on https://api.siliconflow.cn[siliconflow Portal].

The Spring AI project defines a configuration property named `spring.ai.openai.api-key` that you should set to the value of the `OPENAPI_KEY` obtained from runtime environment.

If your model deployment name is not the default `DeepSeek-V3` you can specify it using the configuration property named `spring.ai.openai.chat.model`.

Exporting an environment variable is one way to set these configuration properties.
[source,console]
----
export OPENAPI_KEY=<INSERT KEY HERE>
export SPRING_AI_OPENAI_ENDPOINT=<INSERT ENDPOINT URL HERE>
export SPRING_AI_OPENAI_CHAT_OPTIONS_MODEL=<INSERT MODEL NAME HERE>
----

== Run the demo

[source,console]
----
git clone https://github.com/{project-owner}/{project-name}.git
cd {project-name}
docker compose up
----
